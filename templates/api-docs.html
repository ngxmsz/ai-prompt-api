PromptOpt API 文档

AI提示词优化服务接口说明 · 基础地址：{SITE_URL}

📌 接口概览

所有接口返回统一 JSON 格式：{"code": 状态码, "msg": 消息, "data": 数据}

code=0 表示成功，非0表示失败。

🔧 提示词优化接口

POST/optimize

请求参数

字段类型必填说明
promptstring是待优化的原始提示词，1-2000字符
stylestring否优化风格：precise(精准)/creative(创意)/concise(简洁)，默认precise

返回示例

{
    "code": 0,
    "msg": "success",
    "data": {
        "optimized_prompt": "优化后的提示词内容..."
    }
}

cURL 调用示例

curl -X POST {SITE_URL}/optimize \\
  -H "Content-Type: application/json" \\
  -d '{"prompt": "写一篇文章", "style": "precise"}'

Python 调用示例

import requests

url = "{SITE_URL}/optimize"
data = {"prompt": "写一篇文章", "style": "precise"}
res = requests.post(url, json=data)
print(res.json())

🎟️ 兑换码验证接口

POST/verify_code

请求参数

字段类型必填说明
codestring是兑换码

⚠️ 错误码说明

code说明
0成功
-1通用业务错误（参数错误、AI服务异常等）
-2请求过于频繁，触发限流

📌 备注

  • 单IP限流：每分钟最多20次请求
  • 接口超时时间：15秒
  • 所有接口支持跨域调用
